RouteRequest

data class RouteRequest(val place: String, val distanceKm: Double, val startLat: Double? = null, val startLon: Double? = null, val endLat: Double? = null, val endLon: Double? = null, val mode: String = "green", val seed: Int = 0, val nCandidates: Int = 5, val beamWidth: Int = 3)

Request body sent to POST /route to generate a walking route on the Azure backend.

The backend is a Python service that uses OSMnx to find a mindful walking route on the pre-computed street graph for the given city. Fields use snake_case names via SerializedName to match the API's JSON contract.
