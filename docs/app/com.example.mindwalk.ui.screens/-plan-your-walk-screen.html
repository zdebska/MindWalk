PlanYourWalkScreen

@Composable
fun PlanYourWalkScreen(vm: PlanViewModel, preSelectedMode: String = "", preSelectedDuration: Int = 0, onBack: () -> Unit = {}, onDismissError: () -> Unit = {}, onSelectLocation: () -> Unit, onGenerate: (durationMin: Int, mode: String) -> Unit)

Walk planning screen where the user configures route parameters before generation.

Displays three configuration sections:

  • Start Location — tapping opens LocationPickerScreen; defaults to "Current Location".

  • Walk Goals — duration slider from 10 to 120 minutes.

  • Mindfulness Mode — chip group with "Green", "Quiet", and "Sight" options.

When opened from a preset card on HomeScreen, preSelectedMode and preSelectedDuration pre-fill the slider and mode selection. Tapping "Generate Route" calls onGenerate, which triggers PlanViewModel.generatePythonRoute. A loading dialog blocks interaction while the request is in flight; an error dialog shows the backend response on failure.

Parameters

vm

Shared PlanViewModel providing start location state.

preSelectedMode

Mindfulness mode pre-selected from a home screen preset (may be empty).

preSelectedDuration

Duration in minutes pre-filled from a home screen preset (0 = use default 30).

onBack

Navigates back to HomeScreen.

onDismissError

Clears the error state when the user dismisses the error dialog.

onSelectLocation

Navigates to LocationPickerScreen for start location selection.

onGenerate

Triggers route generation with the given duration and mode.
