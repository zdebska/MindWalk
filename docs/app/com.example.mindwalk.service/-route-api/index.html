interface RouteApi

Retrofit interface defining the MindWalk Python backend REST API.

The base URL is https://katya-route-api-2026.azurewebsites.net/ and is configured in PythonRouteService. All functions return Response wrappers so callers can inspect HTTP status codes and error bodies on failure.
