WalkHistoryViewModel

class WalkHistoryViewModel(app: Application) : AndroidViewModel

ViewModel managing the complete walk history and the user's monthly goal.

Exposes walks as Compose observable state so com.example.mindwalk.ui.screens.JourneyScreen recomposes automatically when new walks are recorded. Current-month progress values (walksThisMonth, distanceThisMonthKm, timeThisMonthMin) are computed lazily from walks and used by the goal progress card.
