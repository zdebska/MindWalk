OnboardingViewModel

class OnboardingViewModel(app: Application) : AndroidViewModel

ViewModel managing the first-launch onboarding flow.

Orchestrates three sub-tasks:

  1. City input — keyboard entry with Nominatim autocomplete (debounced 400 ms).

  2. GPS detection — resolves the device location and geocodes it to a "City, Country" string.

  3. City preparation — calls POST /prepare then polls GET /prepare/status until the backend's OSMnx street graph for the city is ready.

The phase state drives com.example.mindwalk.ui.screens.OnboardingScreen's AnimatedContent to show the correct UI panel.
